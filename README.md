Entry for the [make.fun bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363): one sentence, at most 280 characters, that brings back a childhood memory.

## How it works

`main.py` (stdlib-only Python) writes a single original sentence recalling a
childhood summer evening to `entry.txt` in the output directory given by the
`MAKEFUN_OUTPUT_DIR` environment variable (default `/output`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
